# Mi página web - Juric

## ¿De qué se trata la web?
Esta página web trata sobre la tecnología y su importancia en la vida cotidiana. Presenta información básica sobre el desarrollo web y las herramientas utilizadas para crear una página.

## Herramientas utilizadas
- **HTML5:** para crear la estructura de la página.
- **CSS3:** para darle diseño, colores y estilos.
- **Visual Studio Code:** para escribir y editar el código.
- **Git:** para guardar y controlar los cambios.
- **GitHub:** para alojar el repositorio y compartir el proyecto.

## Archivos del proyecto
- `README.md`: descripción del proyecto.
- `index.html`: estructura de la página web.
- `style.css`: estilos visuales de la página.
